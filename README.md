# My Legal Skills

个人法律技能合集，用于在不同设备和平台间同步。

## 包含的技能

| 技能 | 目录 | 说明 |
|------|------|------|
| 合同审查专家 | `skills/contract-review-expert/` | 商业合同风险审查助手，支持甲方/乙方双视角 |
| 庭审手册生成器 | `skills/court-trial-handbook/` | 民事诉讼案件庭审手册生成，模块化输出 |

## 安装方式

在支持 Skill 的 Agent 平台上，告诉 Agent 从本仓库安装即可：

> 帮我从 GitHub 安装 用户名/my-legal-skills 仓库里的技能
